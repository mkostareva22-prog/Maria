Дневник питания
Приложение для контроля питания и здорового образа жизни.
Основные функции:
- Подсчёт калорий и БЖУ.
- Дневник питания.
- Расчёт нормы калорий по росту, весу и возрасту.
- Контроль снижения веса.
- Упражнения, шаги и расход калорий.
- Напоминания о витаминах по назначению врача.
- Информация о пользе продуктов и пищевых добавках Е.
- Низкогликемическое питание.
